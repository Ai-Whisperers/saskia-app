## Optional — generate starter xlsx for Saskia

Once the new container is running, the **easiest path** for Saskia to
populate her real data is to download the workbook generated from
this local sandbox:

```bash
# Generate locally (already done — see deliverables/saskia-rms-starter-2026-09-29.xlsx)
AIW_SASKIA_DB_PATH=/opt/data/.local/share/AIW-Saskia/rms.sqlite \
  python -c "
from app.rms.db import make_engine, make_session_factory, init_db
from app.services.export_xlsx import to_bytes
engine = make_engine(); init_db(engine)
sf = make_session_factory(engine)
with sf() as s: data = to_bytes(s)
open('/opt/data/saskia-rms-starter.xlsx', 'wb').write(data)
"
```

The 518 KB file is in `deliverables/saskia-rms-starter-2026-09-29.xlsx`.
It contains the full mirror of the local DB — all 78 ingredients, 20
recipes, 183 lines, 30 products, 9 customers, 2081 historical sales,
17,781 stock moves.

**To upload it to the VPS after deploy:**

```bash
# From your laptop, once the new container is up
curl -F "file=@deliverables/saskia-rms-starter-2026-09-29.xlsx" \
  https://saskia-vps.paragu-ai.com/excel/importar?mode=patch
```

That single POST populates everything except Ventas / StockMoves
(those are derived state — they'd need a FULL import which would
overwrite the historical sales). For the demo data, PATCH is enough.

After upload, `/productos` should show 30 products, `/inventario`
should show 78 ingredients, `/recetas/6` should show the seeded
ingredients + real cost.

## Summary

Implements all P1 core workflow improvements for the Saskia RMS product and recipe management.

## Changes

### Products router (`app/routers/products.py`)
- **`POST /productos/bulk-edit`** — JSON endpoint for bulk operations: `price_pct` (±% on sale_price_gs), `set_availability` (bool), `set_category` (string). Returns `{"updated": N}`.
- **`GET /productos/importar`** — renders CSV import form
- **`POST /productos/importar`** — parses CSV (name, sku, category, portion_label, sale_price_gs, yield_percentage, tags), find-or-create per row, returns results with N created/updated/errors. Commits each row.
- **`GET /api/tags`** — returns `{"tags": [...]}` with distinct non-empty tags
- **`GET /api/categories`** — returns `{"categories": [...]}` with distinct category values
- `products_list`: added `tag` and `category` query params with SQL `ILIKE`/exact filtering

### Products template (`app/templates/productos.html`)
- Import CSV button (links to `/productos/importar`)
- Bulk-edit modal: select-all checkbox in table header, per-row checkboxes, modal with 3 action options, fetch submission, success toast
- Tag filter: `mf-pop` combobox fetching `/api/tags`, adds `?tag=` param
- Category filter: `mf-pop` combobox fetching `/api/categories`, adds `?category=` param
- Active filter chips: dismissible pills below toolbar with `×` remove link
- Product image thumbnails: `col-thumb` 40px column with 32×32 cover thumbnails
- `.filter-chip` CSS: dark pill styling

### CSV import template (`app/templates/productos_importar.html`)
- Instructions + CSV format table + file upload form + results display

### Validation router (`app/routers/validation.py`) — NEW
- **`POST /api/validate/recipe`** — validates: name (required, min 2 chars), yield_qty (> 0), difficulty (1–5)
- **`POST /api/validate/product`** — validates: name (required), sale_price_gs (> 0)
- Returns `{}` if valid, `{"valid": false, "errors": {"field": "msg"}}` if invalid

### Recipe form (`app/templates/receta_form.html`)
- Inline photo zone at top of form (shows current photo + "Change photo" overlay) → opens existing photo picker modal
- Difficulty: replaced number input with clickable star rating (1–5 stars, JS onclick)
- HTMX inline validation: `hx-post="/api/validate/recipe" hx-trigger="blur"` on name, yield_qty, difficulty fields; `handleValidation()` JS shows errors in `.field-error` spans
- Unsaved changes warning: `beforeunload` handler, `formDirty` flag cleared on submit

### Product form (`app/templates/producto_form.html`)
- HTMX inline validation on name and sale_price_gs fields with `handleProductValidation()` handler
- Unsaved changes warning: same `beforeunload` pattern

### Recetas list (`app/templates/recetas.html`)
- Difficulty column: `{{ '⭐' * r.difficulty }}` rendering
- Difficulty column header added to table
- Active filter chips below toolbar (q, familia, dificultad, dieteticas, ingredient_id)
- `.filter-chip` CSS

### Router registration (`app/rms/main.py`)
- Added `validation.router` import and `include_router(validation.router)`

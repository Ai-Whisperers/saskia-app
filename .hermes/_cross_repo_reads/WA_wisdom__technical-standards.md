*   **Line Coverage:** **95% minimum.** No code is to be merged into the main branch without 95% unit test line coverage.
*   **Branch Coverage:** **85% minimum.** Every logical path must be accounted for.
*   **Zero-Warning Policy:** "A warning is a bug." The build pipeline must treat any compiler or linting warning as a failure.
*   **Validation:** Documentation must be generated and validated automatically for every iteration.

*   **Standard:** The system must be provider-agnostic.

*   *Mandate:* Every project must have a documented path from V1 to V3.

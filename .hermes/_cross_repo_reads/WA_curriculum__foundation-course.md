# 🏛️ FOUNDATION HALL CURRICULUM

> **"Building the exponential mindset from the ground up."**

## 🎯 COURSE OVERVIEW

**Duration:** 8 weeks  
**Skill Level:** Novice → Journeyman  
**Prerequisites:** Willingness to think differently  
**Outcome:** Exponential thinking foundation

## 📚 WEEKLY STRUCTURE

### **Week 1: Exponential Awakening**
**Theme:** Seeing 1+1=11 for the first time

**Daily Practices:**
- **Day 1:** Linear vs Exponential Observation Journal
- **Day 2:** Compound Thinking Meditation (15 min)
- **Day 3:** Synergy Hunt Exercise
- **Day 4:** Feedback Loop Mapping
- **Day 5:** Exponential Vision Practice
- **Day 6:** Teaching Back What You've Learned
- **Day 7:** Integration and Reflection

**Key Concepts:**
- The Star-Machine Principle introduction
- Exponential vs Linear distinction
- First compounding experiences

**Assignment:** Identify 3 linear traps in your life/work

### **Week 2: System Thinking Foundations**
**Theme:** From tasks to systems

**Daily Practices:**
- **Day 1:** Process Mapping Exercise
- **Day 2:** System Boundary Definition
- **Day 3:** Input-Output Analysis
- **Day 4:** Feedback Mechanism Design
- **Day 5:** Improvement Metric Creation
- **Day 6:** System Documentation
- **Day 7:** System Review and Refinement

**Key Concepts:**
- System components and relationships
- Measurement for improvement
- Simple feedback loops

**Assignment:** Design one simple self-improving system

### **Week 3: Patience and Pressure Alchemy**
**Theme:** Time as strategic ingredient

**Daily Practices:**
- **Day 1:** Time Horizon Assessment
- **Day 2:** Pressure Calibration Exercise
- **Day 3:** Diamond Development Planning
- **Day 4:** Patience Practice (delayed gratification)
- **Day 5:** Progress Indicator Design
- **Day 6:** Maturation Monitoring
- **Day 7:** Value Extraction Planning

**Key Concepts:**
- Diamond-Patience Alchemy
- Strategic patience vs procrastination
- Pressure optimization

**Assignment:** Apply patience alchemy to one project

### **Week 4: Star-Machine Design I**
**Theme:** Your first value-creation system

**Daily Practices:**
- **Day 1:** Value Definition Exercise
- **Day 2:** Machine Component Design
- **Day 3:** Automation Opportunity Identification
- **Day 4:** Setting the 95/85 Standard (Coverage Mandates)
- **Day 5:** Zero-Warning Build Pipeline Design
- **Day 6:** Risk Assessment
- **Day 7:** Implementation Planning

**Key Concepts:**
- Star-machine architecture basics
- **The 95/85 Rule:** 95% line / 85% branch coverage
- Zero-warning policy ("A warning is a bug")

**Assignment:** Complete star-machine design document including coverage enforcement plan

### **Week 5: Exponential Implementation**
**Theme:** Building your first compounding system

**Daily Practices:**
- **Day 1:** V1 Prototype Build (Manual/Prototype)
- **Day 2:** V2 Cleanup & Initial Automation
- **Day 3:** V3 Star-Machine Activation (Full Autonomy)
- **Day 4:** First Feedback Collection
- **Day 5:** Initial Improvement Implementation
- **Day 6:** Performance Review
- **Day 7:** Scaling Preparation

**Key Concepts:**
- **Recursive Improvement (V1-V3):** The path to autonomy
- Iterative development
- Compounding evidence collection

**Assignment:** Build and test your star-machine

### **Week 6: Teaching Exponential Thinking**
**Theme:** Learning by teaching

**Daily Practices:**
- **Day 1:** Identify Teaching Opportunity
- **Day 2:** Prepare Exponential Lesson
- **Day 3:** Teach One Concept
- **Day 4:** Collect Feedback
- **Day 5:** Refine Teaching Approach
- **Day 6:** Teach Another Person
- **Day 7:** Teaching Reflection

**Key Concepts:**
- Exponential teaching methodology
- Learning reinforcement through teaching
- Knowledge compounding

**Assignment:** Teach exponential thinking to 2 people

### **Week 7: Integration and Mastery**
**Theme:** Bringing it all together

**Daily Practices:**
- **Day 1:** Personal Exponential Assessment
- **Day 2:** System Portfolio Review
- **Day 3:** Teaching Impact Evaluation
- **Day 4:** Exponential Habit Formation
- **Day 5:** Community Contribution Planning
- **Day 6:** Legacy Consideration
- **Day 7:** Next Level Preparation

**Key Concepts:**
- Exponential lifestyle integration
- Community building
- Legacy thinking

**Assignment:** Create personal exponential growth plan

### **Week 8: Capstone Project**
**Theme:** Demonstrating exponential transformation

**Project Requirements:**
1. Design and build a star-machine
2. Demonstrate compounding results
3. Teach the concept to others
4. Document the entire process
5. Present to wizard community

**Evaluation Criteria:**
- Exponential thinking demonstrated
- System design quality
- Teaching effectiveness
- Documentation completeness
- Community impact

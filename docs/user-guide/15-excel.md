# 15 — Excel (importar / exportar planillas)

> **Qué es:** la pantalla para bajar tus datos como planilla Excel, o
> cargar datos nuevos desde una planilla.

## Cómo llegar

**Excel** en la barra superior.

![Pantalla de Excel — placeholder screenshot]

## Exportar (bajar datos)

Sirve para:
- Llevar una copia de seguridad a tu computadora.
- Compartir datos con tu contador.
- Analizar cosas en Excel que la app no muestra (ej. gráficos custom).

### Cuándo exportar

| Qué querés | Cómo |
|---|---|
| Todos los productos y precios | Exportar → Productos |
| Inventario completo | Exportar → Ingredientes |
| Ventas de un mes | Exportar → Ventas |
| Merma de un período | Exportar → Merma |

Tocá **Exportar** en la sección que quieras. Se baja un archivo
`.xlsx` a tu computadora.

## Importar (cargar datos)

Sirve para cargar muchas cosas de una sola vez. Por ejemplo:

- 100 ingredientes nuevos que tenés en una planilla.
- Cambios de precio en masa.

### Formato esperado

La planilla que importás tiene que tener **exactamente las mismas
columnas** que la app exporta. Si no, la importación va a fallar.

**Para importar:**

1. Exportá primero (para tener el formato correcto).
2. Modificá la planilla en Excel.
3. Guardá como `.xlsx` (no `.csv`).
4. Andá a Excel → Importar.
5. Elegí el archivo.
6. La app te dice cuántas filas se importaron y cuántas fallaron.

### Cuándo NO usar importar

- **Para 1 o 2 cambios.** Es más rápido editar directamente en la app.
- **Si no estás segura del formato.** Mejor pedile ayuda a Iván.

## Tu día a día con Excel

**No es una pantalla diaria.** La usás solo cuando:

- Querés una copia de seguridad (1 vez por mes).
- Necesitás compartir datos con alguien externo.
- Vas a cargar muchos productos/ingredientes de golpe (ej. al empezar).
